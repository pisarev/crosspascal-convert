Model contract

The optional vision contract describes the model task and input layout. Select a task to write manifest.txt and manifest.json beside the module. Leave the task empty to build without a vision contract.

Choose the actual Det or Rec role. Rec requires an explicitly selected dictionary, never an inferred file. Preview hashes the selected graph, weights, config and dictionary and Build refuses changed bytes. This is SCANNED_NOT_LOCKED, not a WSL compiler-held snapshot or an OCR numerical verification. Optional experimental Win32-held stage is OFF by default; WSL/DrvFs compatibility has not been accepted. On failure there is no fallback to the mutable original. Private stages are retained for owner inspection and occupy disk space.

An adapter is required once a task is chosen. It names the pre/post-processor, for example yolo11, rtdetr, tensorflow or birefnet. The task-specific fields appear for the task that uses them: thresholds for detection, mean and std for classification, the keypoint count for pose. A detector such as rtdetr that carries no thresholds simply leaves them blank. The labels file is recorded with the build but not yet written into the manifest.
